# Hardware control

Interfaces to the hardware of the acquisition setups:

| folder | hardware |
|---|---|
| [NIdaq/](./NIdaq/README.md) | National Instruments DAQ cards (acquisition and stimulation) |
| [FLIRcamera/](./FLIRcamera/README.md) | FLIR cameras (face camera, rig camera) |
| [Thorlabs/](./Thorlabs) | Thorlabs scientific cameras (imaging camera) |
| [QCamera/](./QCamera) | QImaging cameras through MicroManager |
| [toupcam/](./toupcam/README.md) | Toupcam cameras |
| [LogitechWebcam/](./LogitechWebcam) | webcam |
| [Dummy/](./Dummy) | dummy devices (demo mode, when the hardware is not available) |

For the installation of an acquisition setup (python environment, drivers, cameras), see the [installation instructions](../../../docs/install/acquisition.md). The list of the hardware is in [docs/hardware](../../../docs/hardware/README.md).
